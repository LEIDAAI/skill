# skill

店雷达技能导航 · 多平台（1688 / OZON / 亚马逊 / TEMU）

## 内容

- `index.html` — 技能导航页：按平台 × 场景组织技能，每个技能带「一键复制调用指令」，粘贴到任意 WorkBuddy 对话即可使用（对话已连 MCP 直接执行）。
- `ozon-selection-search.md` — 「Ozon选品搜索」技能底稿（已录入店雷达管理系统后台）。

## 使用

直接打开 `index.html`，或通过 GitHub Pages 在线访问：

```
https://leidaai.github.io/skill/
```

## 功能

- 平台标签切换（全部 / 1688 / OZON / 亚马逊 / TEMU）
- 场景筛选（选品 / 竞品 / 类目趋势 / 商品解析 / 店铺分析 / 利润测算 / 选品报告）
- 搜索、添加自定义技能（localStorage 持久化）、导入 / 导出 JSON
- 各技能卡片：复制调用指令 / 查看 SKILL.md / 删除（自定义技能）
