## 原始场景口径（业务目标与阈值依据）
下文是场景表原文，包含历史工具名、示例及旧执行建议；与本技能的「执行步骤」「公共纪律」冲突时以后两者为准。原文中的降档只用于另列诊断结果，不能放宽严格达标口径；没有真实字段时标为不可判定。
分析Amazon美站一批竞品ASIN的Listing材质词/功能词渗透率（卖点横向统计）：
1. 批量拉取：asin_detail逐ASIN获取标题+五点描述，记录获取状态；失败项标FAILED并剔除分母，备注原因（沿用『ASIN详情解析·跟款参考』零编造纪律）
2. 文本预处理：标题与五点统一小写、连字符标准化（faux-leather=faux leather）、多余空格清理
3. 标签词典（标准词-扩展变体映射，按类目切换词典，默认箱包版）：
【材质词】PU leather（含faux leather/vegan leather/PU）/ Polyester / Nylon / Canvas / Corduroy灯芯绒 / Oxford布 / Neoprene / PVC / Genuine leather
【功能词】USB充电（USB port/USB charging/built-in USB归一）/ 防泼水Waterproof（water-resistant/Waterproof归一）/ RFID防盗 / 可折叠Foldable（collapsible归一）/ 大容量Large capacity / 多口袋Multi-pocket / 可扩展Expandable / 笔电隔层Laptop compartment / 透气背垫 / YKK拉链
4. 逐ASIN标注：遍历词典匹配（大小写不敏感+同义词归一），命中打标并记录位置（标题/五点/两者）；仅基于实际获取文本标注，禁止虚构未出现的标签
5. 渗透率统计：各标签命中ASIN数÷有效ASIN总数；区分标题命中占比与五点命中占比；降序排列
6. 输出三层：①ASIN明细表（ASIN/标题摘要/材质标签/功能标签/状态）②标签词典（标准词/变体/归一规则）③汇总统计表（类别/标准词/命中数/总数/出现率/标题命中/五点命中）
7. 【差异化机会识别】（本场景核心洞察）：低占比标签（<10%）若标题命中占比高（如3/4命中在标题）→说明该卖点稀缺但被头部当核心词用=差异化布局机会；高占比标签（>50%）=类目标配，不写反而缺竞争力；输出机会清单+标配清单
8. 【样本量纪律】有效ASIN分母披露；同父体变体合并计一次

3. 词表可按用户主题裁剪；统计口径写明基于五点+标题，不含评论。
