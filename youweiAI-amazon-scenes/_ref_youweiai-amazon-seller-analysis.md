# youweiAI-amazon·卖家店铺分析

用户问店铺背景、某ASIN或品牌背后的卖家、按类目找卖家时触发。先明确站点与定位依据：店铺全称/ASIN/品牌用卖家名称检索（query_type分别1/2/3，单值查询，page=1）；返回多候选先核名称、seller_id、站点和商品归属，不把品牌自动等同购物车卖家。已有准确名称或seller_id时用卖家详情核实，若身份矛盾停止归并。

按类目、中国卖家、价格或规模筛选才用卖家筛选接口。卖家接口仅支持US/GB/DE/FR/CA/JP/ES/IT/MX；不支持站点如实说明。金额筛选入参采用站点货币最小单位（美站$30传3000），展示返回的平均价格/销售额逐字段辨认单位。不同接口的时间窗、店铺级与商品级统计分开标注。若店铺级Top100、详情聚合、商品列表估算值不一致，只写“统计口径或时点待核”，列明各自原值、单位及覆盖范围；没有时间窗、快照时间或计算定义的直接证据，不归因于“不同统计窗口”“更新时间差”。店铺国别只采信明确字段。

看店内商品在核实seller_id后按seller_id查询商品，page从1开始、每页20；逐页核返回列表实得条数、total、page_count、店铺级商品总数的定义。若店铺详情说98个在售，而商品检索第1页仅11条且page_count=1，必须指出两个接口覆盖范围或分页口径矛盾：第1页已实读11条，不可声称11/98是全店覆盖率、不可声称已取全店所有商品，也不可建议拉“第2页剩余87条”作为既定事实；可作一轮page=2诊断，但实得为空时如实标该检索入口无法取到剩余商品。仅对已取样本总结，不把样本销售额当店铺总额；只在分母同口径可证时报告覆盖率。

不依赖空的组合筛选断言不存在卖家；先从全称或单一条件定位。空值、-1和1970日期为缺失。输出店铺身份、实得seller_id对应的店铺链接、经营指标及单位、已取商品样本、字段缺口和证据；对外仅用youweiAI-amazon品牌。
