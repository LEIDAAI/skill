# youweiAI-amazon·关键词挖掘

## ★ 必填项与追问（强制执行，优先于下文任何“缺参数就问一次”的表述）

### 必填项
站点；种子词 或 目标ASIN

### 可选/可默认项（缺了就按“未限定”处理，并在报告数据缺口里注明，不代填、不追问第二遍）
词量、CPC上限、是否要趋势序列

### 追问方式（必须用 ask_user 表单，禁止纯文字发问后干等）
1. 一次性收齐所有缺的必填项，**不要一项一项挤牙膏**；缺 1 项就只问 1 题。
2. `ask_user` **必须单独调用**，不与 `view_skill` 或任何业务工具并发。
   - **每题必须显式写 `id`（非空字符串、同次调用内唯一）**，例如 `{"id":"target_product","question":"...","options":[...]}`；漏 `id` 会被接口直接报错 `Each question requires a non-empty id`，客户就看不到选项卡片。
   - `allow_other` 必须写在 **question 对象内**（不是顶层）。
3. 每题 **2–3 个 options**，每项必须含 `label` 和 `description`；需要自由输入（如自定义类目、其他子类）时设 `allow_other=true`。
4. 选项要**给客户可直接点的具体候选**，不要只写“是/否”。例：
   - 站点：`美国站`（市场规模最大，竞争最激烈）/ `德国站`（欧洲头部，需关注VAT）/ `日本站`（本土竞品少）
   - 类目：给出该站真实子类名 2-3 个 + `其他`（允许输入）
   - 图片/文件缺失：`我上传图片`（支持图片直链或附件）/ `我先贴商品链接，你来提图` / `跳过图片，只用链接`（若本场景必须图片则不提供此选项）
5. 用户已回答的项不再重复问；用户说“你看着办/按默认”时，取最保守口径并声明假设。
6. 收到回答后**直接继续原任务**，不要复述问题、不要重新确认。

### 缺图/缺文件的专用问法（仅场景14/15/21这类必须文件的技能）
- 场景15 缺图片 → 必须用 ask_user 提示：“本技能需要一张商品图才能反查 1688 货源”，给出 `上传图片` / `贴商品链接由我取图` / `先看这个技能怎么用`（说明+示例图格式）三个选项，**不得用文字猜商品、不得编造货源**。
- 场景14/21 缺 ASIN/售价/文件 → 同上，给出可点的补参路径，不得静默按默认值跑。

### 报告收尾必带“下一步引导”（不做 ask_user，只给可点的文字建议）
HTML 报告结论区之后，固定给 2–3 条**下一步可做**的引导，例如：
- 「要不要把这批款的差评拉出来看改进点？（场景19）」
- 「要不要按 $25/$30/$35 三档做毛利敏感性？」
- 「要不要换德国站看同样条件有没有机会？（场景10）」
只写建议文字，**不要在结尾强制再发 ask_user**，避免客户被反复弹窗卡住。

## 商品身份与真实主图硬规则（2026-11-19，最高优先级）
本节覆盖旧文中“主图若实返”“标题摘要”“仅候选表需主图”和空白占位的宽松表述；其余业务门槛、证据、异常及效率规则继续执行。

1. 适用全部具体商品结果：主榜、深度核验表、对照/对比表、推荐和剔除清单、变体表、单品卡、附录及全部命中清单。每张相关表都必须在商品所在行、对比商品列头或本表绑定的单品身份格展示身份信息；不能以主表已有为由省略附录或另一张表的身份列。
2. Amazon商品身份最少为：真实主图、接口返回的完整原始商品标题、ASIN、PASIN（父ASIN）并列展示。完整标题须可见并自动换行，不以中文概括、关键词、截断摘要替代。PASIN仅采用同站点同商品实际返回的parent_asin/parentAsin/PASIN或已核验变体关系；没有证据统一写“未返回”，严禁复制子ASIN填父ASIN、按标题/相似图/品牌猜父体，也不把样本子体销量相加冒充父体总销量。
3. 1688商品身份最少为：真实主图、接口返回的完整标题（title/subject等真实字段）、offerId。供应商名、店铺ID、SKU或“图搜结果”不能替代商品ID。Amazon与1688同款比对两端都独立展示各自身份，不把一端主图/标题/ID移给另一端。
4. 主图只取同商品ID、同站点的真实返回图片字段；主图字段名按实际schema识别，列表与详情取数可复用。禁止把图搜关键词、图片描述/alt文字、“查看图片”链接、空框、占位图或其他款图片冒充真实主图，禁止凭ASIN/offerId编造图片URL。
5. 缺主图、完整标题或父体字段时，先检查已取原始字段，再按同ID补查当前实际可用的详情、内容或变体通道；只补缺项，不重跑整条检索。补查仍无图时该商品格明确写“主图未返回”；URL加载失败时移除破图并显示“主图加载失败”。标题无法取得写“完整标题未返回”，PASIN无证据写“未返回”；在数据缺口逐项列商品ID、缺字段及实查状态，不伪称完整交付，也不删除身份列掩盖缺失。
6. 每个真实主图以48–80px缩略图展示，object-fit:contain；悬停打开320×320白底圆角阴影原图浮层，mousemove跟随指针，靠近右/下边缘自动翻转，mouseleave隐藏，全报告共用一份JS。data-big只能使用该商品真实原图URL；图失败状态必须可见文字，不能只留空框。图片悬停不以同一张图替代其他商品的图。
7. 完整标题和商品ID均链接到对应站点、对应ID的真实商品页，新窗口使用target="_blank"及rel="noopener noreferrer"。ASIN/PASIN区分标签；父体未返回不生成假链接。1688使用返回且与offerId一致的商品链接；不得把搜索结果页、图片搜索页或店铺页冒充商品直达链接。外部返回文本须HTML转义，href/src仅接受http/https且与字段身份核对。
8. 严格0结果如实写0与原因，不生成空商品表或编造候选；真实诊断候选单列并标放宽项。纯关键词、类目、费用情景、供应商聚合表不硬塞商品、图片或ID；一旦其中列出具体代表商品，该商品身份仍执行本节，不能只留裸ASIN/offerId或简称。
9. 出稿前逐张检查所有含具体商品的表和卡片：真实图片来源与ID一致、完整标题、ASIN+PASIN或offerId、真实直达链接及新窗口、缩略图与320×320悬停、缺失状态逐项可见。缺图补查完成与图片成功加载分别表述；有URL不等于已核验加载成功。
10. 本节仅加固展示与取证，不改底层可执行工具标识或调用schema。对外报告、可复制内容与新增说明只使用youweiAI-amazon，不披露底层第三方名称、内部路由、私有路径或内部地址。
