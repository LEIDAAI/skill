# youweiAI-amazon·关键词挖掘

用户提供种子词、ASIN，或要求热词榜、长尾词、CPC与词位竞争时触发。默认美国站；先加载本技能，仅用当前会话绑定的亚马逊关键词工具。

有种子词先查扩词，再按语义筛掉错类、品牌词和整套商品词；重点词再查关键词详情。给ASIN则反查自然曝光关键词；没有种子词或ASIN时才查热词榜。需要历史趋势才查时间序列，当前未完月不与完整月比较。自然曝光不冒充广告排名；搜索结果注明页码、样本范围、滚动窗口或自然月。相近词搜索人群可能重叠，不把词量相加当市场需求。

推荐CPC空字符串或负数标缺失；90天点击量为0而点击转化率为0、但同时给出购买量或搜索转化率时，不能因为数值同为0就认为漏斗可复核。分别展示各字段原值与定义，标“点击链路不可核”；搜索转化率如来源定义未说明，可作为该工具估计值列示，不得按点击量/购买量自行验算，也不据此断言真实转化能力。首页低评论率、非Top100占比只描述该工具样本范围及字段定义；缺分母、阈值或逐条样本时，不据此宣称新链接可切入、竞争最低、流量容易获取、广告必定有效。同比/年累计增长要核两期同长度同窗口；否则列原值并标不可比。未知词返回空如实说明。

输出核心/腰部/长尾词表，逐词列搜索量、估计转化率、CPC、语义、竞争证据、日期与页码；优先顺序仅为词语相关性和当前指标下的验证顺序，说明还需商品检索及投放实测，不称已证机会。对外只用youweiAI-amazon，不披露底层数据供应商。
