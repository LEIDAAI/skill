# youweiAI-amazon·选品搜索

## 触发
用户要求按站点、产品词、类目、售价、估计月销量、评分、上架时间等条件搜索商品或生成候选表时加载。只在确需查类目节点时调用类目搜索；已知 ASIN 的单品详情转商品解析技能。

## 输入与工具
解析站点（默认美国站）、关键词、产品用途、硬条件、目标条数、日期口径。调用当前会话已绑定的亚马逊商品搜索、按名称搜索、类目搜索及商品详情工具；使用工具实际参数结构，不调用不存在的后台任务/轮询接口。工具未提供或报错时说明原因，不编造结果。

## 流程
1. 类目条件先查节点名称及层级；多候选时核准后再筛。关键词宽召回偏题时可补标题/属性搜索，两路按 ASIN 去重；硬条件必须在最终候选重新核对，诊断性放宽结果不得回填。
2. 搜索从第1页开始，每页20条。按请求数量和结果继续分页，记录接口、页码与样本数，不声称覆盖全库。检查标题、类目、价格币种、月销、商品用途；麻将包要排除牌、麻将垫、牌架、整套附赠包等非目标，垫收纳袋和装牌袋区分标注。
3. 严格上架窗口要逐条以详情 listing_date 核对，列表 online_date 只作预筛。FBA或跨境条件须用详情字段验证。详情返回 ASIN 与请求不一致或身份矛盾时剔除并披露。缺失值与0区分。
4. 返回为子体时按 ASIN 列实际观测值；按 parent_asin 归组只算已见样本中的系列数，不能将子体月销相加或称作父体总月销。需要完整变体另告知查询开销。

## 输出
给出样本页数、原始与有效数量、硬条件核验情况；表格列主图（若实返）、商品标题和商品页链接、ASIN/parent_asin、价格和币种、估计月销、上架日及页码。标题链接指向对应站点 /dp/{asin}；卖家只有取得 seller_id 才给店铺链接。默认按核心指标降序。若渲染交互表格，主图悬停显示随鼠标且边缘翻转的320×320白底圆角预览；聊天纯文本表格按实际能力输出。末尾给剔除/待核理由、取数日和样本局限。对外仅使用 youweiAI-amazon，不输出底层接口供应商品牌。

5. 商品明细表（候选/入选表）必须含「主图」列：用本次接口实得的图片URL（image/og_image等实返字段），不得因列多或条数多省略；图片加载失败留缺并标注，不用占位图。HTML报告中的主图须配悬停放大浮层：320×320、白底圆角阴影，mouseenter/mousemove跟随指针，靠近右/下边缘自动翻转，mouseleave隐藏。Markdown表格至少保留主图列的img引用。

## 计数和来源复核
只有逐条读取并实际计数时才能报原始数、ASIN去重数及有效数；不能用已翻页数乘20推算，也不能凭印象写“约N款”。每一条候选须记录实际命中的检索入口与页码；同一 ASIN 同时命中两路才写“同见”。若无法回溯某来源页码，标“页码未核”，不可用另一入口页码代替。最后输出前核对正文和表格之间的筛选结果、页码、用途是否矛盾；一旦矛盾，先删去未核计数或来源叙述。查询日可用本次对话日期，不为取得日期单独调用与选品无关的工具。

## 多入口范围与日期复核
跨类目节点、关键词、诊断性放宽查询时，分别列出每个入口实际使用的筛选条件、页码、实得数、去重前后数及是否参与最终候选；诊断样本须单列，不能与全硬条件命中的原始量混写，也不能将仅查一页说成全入口结果。节点层级无法核实则仅称按该节点查询，不把一个节点擅自定义为主节点或整个品类。结论只称本轮已查节点与页码命中几条，不使用“仅有”“当前头部均为老品”等覆盖全品类的说法。
详情 listing_date 用于本次严格日期筛选时，也要和 online_date、days_on_shelf、查询日交叉核验；字段语义或日期不自洽时列出原值和差异，标记日期口径待核，避免同时报告互相冲突的“在架天数”。不得把 online_date 与 listing_date 日期不同本身断定为数据错误。coupon 正值或负值须按原字段语义说明，coupon=0 不推断有券；商品详情与列表估计月销售额若冲突，逐项验算后并列标注。

## 大批量拉取与表格交付
用户要求拉取 N 条（如 500、1000 条）时：同步翻页拉满或拉到池底为止，不提交异步任务、不轮询状态。每页20条，页数=N/20 向上取整；拉满后用 ASIN 去重并如实报告「请求N条/实得M条/去重后K条」；池子不足 N 条时说明「该条件下共X条，已全部拉取」，不凑数。
类目条件必须先用类目名称检索核实节点名称与层级再使用：名称含 Dresses 的节点要区分「Women's Dresses 主类目」与「Activewear/Tennis Dresses 等子类目」，只按用户语义选节点并在口径里写明节点全名；不得凭 node_id 猜测类目含义。
Markdown 超过约40行的长表改为完整 html 代码块交付（含表格、排序、口径说明），不使用外部表格组件或网关提交；组件无数据或加载失败等同交付失败。表格必须含主图列（用本次实返图片URL，加载失败留缺标注），按用户指定指标降序。
网关同步任务返回的自述note（如"符合筛选条件的真实结果共X条，重复检索也不会更多"）不可作为事实转述：实际条数与总量必须以本会话工具返回的 page_count/pages/saved_count 原始字段核实；发现任务在目标条数前停止时，先用末页+1做独立探针页验证 page_count，再决定是续翻还是如实报告截停，禁止把截停样本称为"已全部拉取"。
HTML商品表的主图列必须实现悬停放大浮层：320×320白底圆角阴影、mouseenter/mousemove跟随指针、靠近右/下边缘自动翻转、mouseleave隐藏——只放img不算完成。
