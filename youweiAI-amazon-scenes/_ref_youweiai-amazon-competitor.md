# youweiAI-amazon·竞品分析

## 触发与输入
用户给出 ASIN、亚马逊链接或竞品名称，要求判断竞品表现、费用、流量、趋势或多商品比较时加载。默认美国站；品牌名称先检索候选并核身份。

## 执行
1. 使用当前会话绑定的商品详情工具逐一核对请求与返回 ASIN、标题、品牌、规格和站点；身份矛盾即停止该条，不把相似搜索当详情。候选的容量、材质、保温结构分层核实：属性里的重量如“2 pounds”不是容量体积单位，不能按水密度换算后说已验证32 fl oz；只有标题声称32oz时标“标题声称，容量待核”。不得在结论把待核属性称为已满足同容量要求。
2. 只在用户需要历史走势时查趋势，按完整可比时段分析；综合报告才查单品报告；流量与评论按需查，空数据如实标未取到。多竞品比较同站点、同规格与同窗口。不同价带只能作有限对照，不直接判输赢。
3. 直读售价、FBA费、佣金及接口估算利润/利润率。佣金为0/-1或缺失标待核；平台估算未扣采购、头程、广告、退货，不称真实净利。售价乘估计月销是理论乘积，不能当实际营收；若同时返回估计月销售额，应先计算乘积并与该字段比较（允许合理取整差）。两值吻合就写吻合，不得凭“估计值”性质声称相互冲突；相差时列实际差额、口径待核，不把它说成真实订单。不得自行套用“常见15%类目佣金”衡量准确性。
4. 子体 ASIN 与 parent_asin 区分，已见子体销量不可相加称父体总销量。原始评论与跨变体评论分清，来源日期注明。online_date、listing_date、days_on_shelf 含义不同且可能冲突；仅日期值不同本身不等于数据错误，只有经语义及时间核验后才标待核，不能选一个称严格上架日。

## 输出
给出身份核验表、实得价格/销量/费用、可比性分级、缺失字段、风险与可验证动作。标题链接到 /dp/{asin}，有实得 seller_id 才给店铺链接；缺历史不造趋势，缺成本不报真实利润。对外统一标 youweiAI-amazon，不披露底层供应商。
