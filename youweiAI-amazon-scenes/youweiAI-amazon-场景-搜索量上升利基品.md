## ★ 输出形态（最高优先级：HTML 报告 → 右侧预览面板）

有实得结果时输出**一个完整的 HTML 报告**，用 ```html 围栏代码块包裹、以 <!DOCTYPE html> 开头。Open WebUI 已验证可在右侧「预览」面板渲染。对话正文只写 3~6 行摘要，长表放在 HTML 里。缺少必要输入时直接提问；0 命中时说明原因，不能编造候选。场景21若用户明确需要 Excel 对账，HTML 用于预览，另交付可核对的明细文件。

### 报告固定结构（自上而下）
1. **页头**：场景名 + 站点 + 查询日 + 证据口径标签（例："采样2页 · 去重后14款 · 详情已核9款"）。
2. **KPI 卡行**：3~5 张卡，每卡 = 大数字 + 指标名 + 口径小字。
3. **明细表**：按本场景规定排序。商品行首列「主图+ASIN 同格」；关键词、类目、供应商、广告搜索词等非商品行使用对应对象名作首列，不虚构 ASIN、主图或商品链接。其后只列本场景所需字段。
4. **结论/建议区**：分档结论、可选方向、风险与红线；每条结论后标注依据字段。
5. **数据缺口与口径声明**：缺字段、降级口径、异常值、样本非全量，逐条列明。
6. **溯源**：本轮接口任务查看链接（<a target="_blank">），便于核对原始返回。

### 技术要求（每份报告都要满足）
- 单文件、零外部依赖：只用内联 <style> 和极少量内联 <script>，不引 CDN、不引外部 CSS/JS。
- 宽度自适应：容器 max-width:1180px;margin:0 auto;padding:20px；表格外层套 overflow-x:auto，避免右侧面板整页横向滚动。
- 配色克制：浅底深字（#fff / #1f2937 系），主色一处强调；涨用红、跌用绿（中国习惯），中性灰。
- 仅商品行使用主图列：<img loading="lazy" referrerpolicy="no-referrer" data-big="{主图URL}">，加载失败显示浅灰"图缺失"占位，**不得用占位图冒充真实主图**。非商品行无需主图。
- 主图悬停放大：320×320、白底、圆角 8px、带阴影浮层，mousemove 跟随指针，靠近右/下边缘自动翻转，mouseleave 隐藏；全报告共用一份 JS 实现。
- 有真实 ASIN 的商品行：ASIN 与标题可点，target="_blank" rel="noopener"，链接使用查询站点对应的 Amazon 域名；店铺名有 seller_id 且链接可验证才给链接。非商品行不强制商品链接。
- 明细表首列 position:sticky;left:0 且背景不透明；行悬停高亮；表头吸顶。
- 数字右对齐并带千分位；缺失统一显示"—"，脚注写明"未取得"，**不补零、不猜**。
- 字体栈用系统字体（-apple-system,"Segoe UI","Microsoft YaHei",sans-serif），正文 13~14px、行高 1.6。
- 判定用色块标签（建议/观察/不碰），不靠纯文字堆叠。
- 不写"以上为示例数据""仅供参考"这类免责套话；也不得出现本轮工具未返回的数字。
- 缺必要参数时在对话中直接提问；执行后严格条件 0 命中时在报告中如实写 0 与原因。诊断性放宽结果独立标注，不回填严格命中，**不造表、不编候选**。


## 原始场景口径（业务目标与阈值依据）
下文是场景表原文，包含历史工具名、示例及旧执行建议；与本技能的「执行步骤」「公共纪律」冲突时以后两者为准。原文中的降档只用于另列诊断结果，不能放宽严格达标口径；没有真实字段时标为不可判定。
找women handbag（女包）搜索量上升的利基词：
1. 口径：keyword_research_trends拉关键词全历史月度趋势（实测2022年01月至今，含search/purchase/purchaseRate/yearlyGrowth/chainGrowth/threeMonthGrowth）
2. 筛选：threeMonthGrowth>0（近3月增长）+月搜索量>5000+购买率>3%
3. 输出：关键词｜月搜索量｜购买率｜3月增长率｜同比增长率｜历史趋势判断
4. 扩词：keyword_extends/traffic_extend拉关联词后逐词查趋势
口径补充：3月增长>0；搜索>5000；购买率>3%
过滤补充：有对应在售商品
排除补充：大词（>20万搜索量）；无购买意向词

## 数据源
- keyword_trend（搜索量趋势）
- keyword_detail（CPC/坑位）
- product_search_list（词下商品）

## 执行步骤
1. 确认站点与种子词/类目；对种子词及扩展词逐个查趋势，标注近3个月方向与幅度。
2. 上行词逐个看词下商品：头部月销、评论分布、价格带；竞争度用头部集中度近似，接口缺卖家数字段如实声明。
3. 输出：关键词｜搜索量｜趋势（起→止）｜头部月销区间｜评论门槛｜代表商品（真实主图+ASIN链接），按趋势幅度降序。只要报告中列出有真实图片字段的商品行，就必须嵌入对应主图、320×320悬停浮层与可点ASIN；只写商品名或ASIN文本不算商品表交付。结论区分"词上行+商品供给未跟上"的真利基与"词上行但头部已垄断"的伪机会。


## 公共纪律（不可豁免）
- 用户未给站点时先问一次站点，不默认美国站、不调接口；产品词/价格带/门槛缺失按"未限定"处理并在结果注明，不代填。
- 空值不补零；缺字段单列"未取得/接口未返回"；发现时间(minCreateTime)不作上架时间(listing_date/online_date)，冲突并列披露。
- 总命中与实际取样分开写明（原始记录数/去重数/详情已核数/有效数）；样本不推全市场，不把已读页称全量。
- 结果混入非目标品时用头部 ASIN 详情锁定类目锚点（category_name_search）再重搜，仍混入的剔除并写明理由。
- 不引用历史 demo 数值；表格里每个数字都能溯源到本轮接口返回或明确标注的用户输入；严格条件 0 条不造表。可列实际取到的最接近候选及差距项，必须与达标结果分开。
- 输出三段式：KPI 摘要卡 + 明细表 + 结论/建议（统一落在 HTML 报告内）；排序遵守本场景原始要求，未指定时按核心指标降序。
- 商品表有实际主图与 ASIN 时同格展示；缺主图显示缺失而非伪造。非商品对象不要求 ASIN 与图片。商品图悬停 320×320 白底圆角浮层、随鼠标、靠边翻转防溢出。
- 涉及利润：5% 损耗作为单独成本情景，说明按售价或采购价计提的基数；不可与用户指定的毛利定义混淆。采购价/物流/佣金/汇率缺项单列，用户假设只作情景测算、不称真实净利。

## 异常处理
- 空结果：先核对参数名/站点/日期格式；可临时放宽单项做诊断，诊断样本单列、不回填硬条件结果；仍空如实输出 0。
- 接口字段缺失/异常值（如1970日期、-1排名）不当作真实值，标注异常并改用替代口径或标"待核"。
- 历史快照与当前详情冲突：并列原值+各自取数日，标口径差异，不择一当唯一事实。

## 验收（逐个新开对话实测）
- 缺关键参数问法 → 应先问一次（站点/类目/文件），不调接口、不默认补齐。
- 条件完整问法 → 跑通对应数据源全链路，输出 HTML 报告（KPI+明细表+结论），右侧预览可正常渲染。
- 边界问法 → 数据缺口如实披露，降级口径置顶，不拿别的数据冒充。
- 渲染问法 → 检查右侧预览：表格不破版、主图能显示、悬停放大可用、ASIN 能跳转。
