1. 从用户取得可访问的单张图片及目标属性。按接口当前 schema 调用 `mcp__1688__image_search({req:{imageUrls:[用户提供的单张图片URL]}})`；需要跨平台对照时按 schema 使用 `mcp__1688__global_image_search` 的 `platform:1688`。记录原图、请求、调用日期、状态、错误 ID 与返回候选；图片不同不能合并为同一轮结果。
