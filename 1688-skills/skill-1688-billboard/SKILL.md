# 1688 商品榜

**验收状态：2026-11-11 已完成典型、边界（含排序组合）、正常空结果触发；接口额度错误与整体数据源故障未实测。**

## 触发与输入

- 用户问「1688 商品榜」「某品类热销排行」「上周/上个月的榜单」时进入本技能；问店铺榜进入店铺核验技能，问新品进入新品发现技能。若同时要求核查具体货号，复用榜单返回的 `offerId` 衔接单品深挖。
- 提取：目标商品与必需用途/规格、榜单周期（月/周）、榜单日期、价格区间（¥）、最低周期订单笔数或销量件数、希望展示的条数。未说日期时选**最近一个已结束的完整周期**，在答复写出所选月或周；「最近」并不等于任选一个历史日期。未提供价格、销量门槛时不要替用户添加。用户要求「桌面收纳盒」时，不能把保鲜盒算入合格候选。

## 独立执行步骤

1. 用 `mcp__1688__product_billboard_list`，唯一嵌套参数为 `req`。月榜 `pageType:3`，`date` 填该月第一天，如 `2026-10-01`；周榜 `pageType:2`，`date` 填对应周日，如 `2026-11-08`。日期格式 `yyyy-MM-dd`。以下为已实测历史请求，实际执行时换成用户的关键词及目标周期，不把示例月份称为实时榜：
   - 月榜：`{ "req": { "date": "2026-10-01", "pageType": 3, "keyWord": "收纳盒", "pageIndex": 1, "pageSize": 3 } }`
   - 周榜边界：`{ "req": { "date": "2026-11-08", "pageType": 2, "keyWord": "收纳盒", "beginPrice": 5, "endPrice": 30, "beginOrderCount": 10, "pageSize": 3 } }`；这里只列当次已知显式参数，未记录字段不补写成已实调值。
2. 有用户指定的价格范围才传 `beginPrice/endPrice`；最低周期成交笔数传 `beginOrderCount`，最低周期销售件数传 `beginSaleCount`，不可替换成累计口径 `beginOrdersCount/beginSalesCount`。按销售额排序可传 `sortField:'saleVolume30d',sortType:'desc'`（月榜实测）；检索明确型号可传 `searchType:3`。不要把关键词与排序组合一概判为无效：2026-11-11 已成功返回。改变条件时记录旧、新两份请求。
3. 检查返回 `code`、`totalCount`、`list`。按返回顺序逐行核对标题、`levelName`、用途/规格；「相关」「待核」「错类剔除」分别标注，保留原榜位置，另标筛后序号。`totalCount` 是原始查询命中，不是合格货源数，也不代表已翻完全部页。按 `offerId` 去重；不足所需条数时如实列出已查页和缺口，不自造榜单名次。
4. 输出商品名/`offerId`、榜单日期、列表展示价、数量阶梯（若返回）、周期件数 `saleQuantity`、周期笔数 `orderCount`、预估额 `salesVolume`、相关性结论。展示价与 `quantityPrices` 或 SKU 阶梯价分开；若未核采购量和 SKU，不称成交采购价。引用接口名、调用日期、请求页数及筛选条件；样本不是全量，缺失字段写「—」，单一榜单不作市场增长或下跌判断。
