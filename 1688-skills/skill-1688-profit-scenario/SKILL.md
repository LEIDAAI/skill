# 1688 报价利润情景测算

**2026-11-11 本轮典型、边界、空结果三类触发全部待验；本轮未为本技能调用接口。以下为 2026-11-10 旧报价与静态 SOP。**

## 执行 SOP

1. 确认商品 `offerId`、目标 `skuId`、完整规格和采购数量，复用已取得的 SKU 响应；没有可靠目标价时按需调用 `mcp__1688__ali_offer_sku_prices({req:{offerId:'目标货号'}})`。将该 SKU 报价与商品整体 `priceRanges`、其他 SKU 和不同起批数量分开；不把展示价/最低阶梯价当确定结算价。
2. 收集用户指定的单件售价、运费、其他费用，统一币种及含税口径后计算 `情景毛利 = 售价 - 目标SKU参考采购价 - 运费 - 其他费用`；当售价非零时 `情景毛利率 = 情景毛利 / 售价`。明确列出所有输入是用户假设还是接口参考值；未给出必要输入时请用户补充，不能自造成本或售价。税费、退货、损耗等未计项目逐项注明，不称真实利润或可执行报价。
3. SKU 未匹配或可靠报价为空时记**缺少测算依据**，说明具体缺项；接口 `code 200` 但真实无 SKU 时记**当前货号/规格正常空**，不使用其他 SKU 代替。非200/超时记**接口失败**；额度明确报错或单轮达到10次则停止新调用；报价结构或字段异常记**数据源待核**，保留请求、日期、返回状态。

## 已有证据（2026-11-10）

- `ali_offer_sku_prices({req:{offerId:'734800252457'}})`：白色磁吸166*122 `skuId=5251111954228` 参考¥4.6；无磁吸166*122 `skuId=5949219410490` 参考¥4；商品阶梯500件起¥4。不能以后二者替换目标磁吸规格的参考价。
- 旧报告情景给定的单件假设：售价¥20、运费¥3、其他费用¥2；`20 - 4.6 - 3 - 2 = ¥10.4`，`10.4 / 20 = 52%`。这是情景毛利及情景毛利率，采购价并非确定成交价，也未计所有成本。
- 2026-11-11 没有本技能三类触发实测、正常空报价、额度错误或整体数据源故障的证据；不得将上述历史演算写作本轮实调。
